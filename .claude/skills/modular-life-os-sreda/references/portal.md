# Часть 3. Портал `<Имя> OS`

> Одна страница с боковым меню, как у автора в MM OS: панель слева сворачивается до значков,
> разделы раскрываются списком, на телефоне меню выезжает по кнопке. Первая вкладка «Обо мне»,
> вторая «Бренд». Оболочка готова в `$SKILL/portal-template/`, агент только переносит данные.

## Перед сборкой

Спроси одним сообщением:

> Давай соберём твой портал. Как его назвать? Два слова, второе обычно OS: «ANNA OS», «MAX OS».
> И одна строка подписью под названием, например «личный портал» или «студия Анны».

Нужны готовые `about-me/` (часть 1) и `brand/style-reference.md` (часть 2). Бренда ещё нет —
портал собирается, страница «Бренд» показывает «пока нет», в итоге пишешь, что часть 2 не пройдена.

## Как собрать

1. Скопируй шаблон: `cp -R "$SKILL/portal-template/." "<путь>/portal/"`. Папка уже есть —
   ничего не затирай, покажи, что там, и спроси.
2. Заполни `{{…}}` в `portal/CLAUDE.md` и `portal/00-overview.md`.
3. **`portal/data/about.js`** — из `about-me/`, только его словами:

   | Поле | Откуда |
   |---|---|
   | `name`, `hit`, `oneLiner`, `facts` | `about-me/profile.md`: имя, кто он одной строкой, 3–4 факта пилюлями |
   | `profile` | `about-me/profile.md`, по абзацу |
   | `projects` | `map.md` и модули проектов: имя, что это, статус |
   | `goals` | `about-me/goals.md`: формулировка, цифра, срок. Цифры нет — так и пиши |
   | `talk.do`, `talk.dont` | `about-me/how-to-talk-to-me.md`: «Как надо», «Как не надо» |
   | `quotes` | `about-me/verbatim.md`: 3–5 самых характерных фраз дословно |

4. **`portal/data/brand.js`** — из `brand/style-reference.md`, раздел в раздел:

   | Поле | Раздел MD |
   |---|---|
   | `portal` | название и подпись, которые он дал. `key` — короткое имя латиницей |
   | `tokens` | 2. Цвета: `ink`, `white`, `accent`, служебные. `light*` — светлая тема интерфейса из его светлых тонов |
   | `fonts` | 4. Типографика: семейство и ссылка Google Fonts. Своих файлов — положи в `portal/fonts/` и пропиши в `files` |
   | `hero` | 1. Коротко: название стиля, слово-акцент, две строки, три пилюли (холст, шрифт, цвета) |
   | `colors` | 2. Цвета: ядро, служебные, правила (`ok: false` — запрет) |
   | `canvases` | 3. Полотна: CSS целиком |
   | `type` | 4. Типографика: начертания и шкала, `base` — ширина холста |
   | `shape` | 5. Холст и формы: размер, поля, факты, скругления |
   | `components` | 6. Компоненты: живая вёрстка HTML + общий CSS, только его токены |
   | `slides` | 7. Образцы: 3–5 кадров носителя вёрсткой. Размеры внутри в `cqw`: 1 cqw = 1% ширины холста, 84 px на холсте 1080 → `7.8cqw` |
   | `rules` | 8. Можно и нельзя |

   Заполнил — удали `example: true` в обоих файлах. Пока строка стоит, портал показывает
   плашку «пример», а `check.py` не пропускает.
5. Впиши модуль `portal` в `map.md` и в корневой `CLAUDE.md` («показать себя, свой стиль глазами →
   `portal/index.html`»). Прогони `python3 architecture.py` и `check.py`.

## Чего не делать

- Не переписывать оболочку `index.html`: меню, панель, темы, телефон уже работают и проверены.
- Не ставить в портал цвет или шрифт, которых нет в `brand/style-reference.md`.
- Не рисовать компоненты и образцы картинками: только вёрстка из его токенов.
- Не выдумывать текст «Обо мне». Пусто в файлах — пустой массив, портал сам покажет «пока нет».

## Проверь и покажи

Открой `open "<путь>/portal/index.html"` и пройди сам:

1. Первая страница — «Обо мне», в меню два раздела: «Я» и «Стиль».
2. Каждый пункт открывает свою страницу, активный пункт белый.
3. Стрелка у пункта раскрывает подразделы, клик по подразделу прокручивает к секции.
4. Кнопка у логотипа сворачивает панель до значков и разворачивает обратно, клик по значку открывает раздел.
5. После перезагрузки тема, свёрнутость панели и открытые разделы на месте.
6. Обе темы читаются: нет светлого текста на светлом и тёмного на тёмном.
7. Клик по цвету копирует значение.
8. Узкое окно (как телефон): панели не видно, кнопка меню её открывает, тап мимо закрывает,
   страница не едет вбок.

Пришли человеку скриншоты: компьютер в тёмной и в светлой теме, телефон с открытым меню. И путь к файлу.
Спроси: «Что не похоже на тебя?» Правки вносишь сначала в MD, потом в `data/*.js`.
