# CLAUDE.md — Brand

> Правила этого модуля. Сначала прочитан корневой `CLAUDE.md`, потом этот.
> Конфликт — прав корневой.

## Что это

Канон: как всё, что делает {{ИМЯ}}, выглядит. Общий для всех модулей, внутрь проектов
не копируется. Здесь цвет, шрифт, формы, компоненты и то, чего делать нельзя.

Короткое правило: **в brand то, по чему сверяются; в проекте то, из чего собирают.**

## Что читать первым

1. `style-reference.md` — источник истины по визуалу: цвет, типографика, формы, компоненты
2. `00-overview.md` — что где лежит в модуле и откуда взят стиль

## Правила модуля

1. **MD — истина, HTML — витрина.** Правишь стиль — правь `style-reference.md`, потом обнови блок `TOKENS` в `style-reference.html`. Наоборот нельзя.
2. **Канон не копируем в проекты.** Проект ссылается на `brand/style-reference.md`, своей копии токенов не держит.
3. **Значение только из источника.** Цвет, шрифт, радиус берутся из его дизайн-системы или референсов. Чего в источнике нет — в разделе «Открытые вопросы», а не на глаз.
4. **Каждый токен с происхождением.** Рядом со значением написано, откуда оно: файл, ссылка или номер референса.
5. **Канон не переписываем из проекта.** Правило устарело — говоришь {{ИМЯ}}, правим здесь.
6. **Несколько вариантов — одной страницей.** Больше одного варианта визуала сдаётся страницей-сравнением, а не россыпью файлов.
