# 00 — Brand

> Карта модуля. Агент, зайдя в папку, читает её первой.

| Файл / папка | Что это | Когда обращаться |
|---|---|---|
| `CLAUDE.md` | Правила модуля | Перед любой работой здесь |
| `style-reference.md` | Источник истины по визуалу: токены, компоненты, запреты | Перед любой вёрсткой, картинкой, страницей |
| `style-reference.html` | Витрина стиля: палитра, шрифты, формы, компоненты вживую | Показать стиль человеку, сверить глазами |
| `references/` | Исходники, из которых собран стиль: скриншоты, файлы дизайн-системы | Проверить, откуда взято значение |
| `architecture.json` | Машинная карта модуля. Собирается сама | Быстрый поиск по меткам внутри модуля |
