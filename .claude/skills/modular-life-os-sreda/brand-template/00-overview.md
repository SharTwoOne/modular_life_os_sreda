# 00 — Brand

> Карта модуля. Агент, зайдя в папку, читает её первой.

| Файл / папка | Что это | Когда обращаться |
|---|---|---|
| `CLAUDE.md` | Правила модуля | Перед любой работой здесь |
| `style-reference.md` | Источник истины по визуалу: цвета, полотна, типографика, холст, компоненты, образцы, запреты | Перед любой вёрсткой, картинкой, страницей |
| `references/` | Исходники, из которых собран стиль: файл дизайн-системы, скриншоты, свои работы | Проверить, откуда взято значение |
| `architecture.json` | Машинная карта модуля. Собирается сама | Быстрый поиск по меткам внутри модуля |

Витрина стиля — страница «Бренд» в портале: `portal/index.html#brand`.
