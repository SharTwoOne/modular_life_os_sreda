# CLAUDE.md — Portal

> Правила этого модуля. Сначала прочитан корневой `CLAUDE.md`, потом этот.
> Конфликт — прав корневой.

## Что это

Личный портал {{ИМЯ}}: одна страница с боковым меню, которая открывается двойным кликом
и одинаково работает на компьютере и на телефоне. Сейчас в меню два раздела: «Обо мне»
и «Бренд». Дальше сюда добавляются новые: карусели, видео, работы.

## Что читать первым

1. `00-overview.md` — что где лежит и как добавить раздел
2. `data/brand.js` — данные страницы «Бренд», переносятся из `brand/style-reference.md`
3. `data/about.js` — данные страницы «Обо мне», переносятся из `about-me/`

## Правила модуля

1. **Портал показывает, а не хранит.** Истина про человека — в `about-me/`, про стиль — в `brand/style-reference.md`. Сначала правишь MD, потом переносишь в `data/*.js`.
2. **Оболочку не переписываем.** Меню, сворачивание панели, темы, телефон и адреса в `index.html` уже работают. Меняем данные, а не каркас.
3. **Только его значения.** Цвета, шрифты, слова — из его файлов. Чего нет — пустой массив, портал сам покажет «пока нет».
4. **Новый раздел меню** — объект в `NAV` внутри `index.html`, блок `<div class="page" id="…">` и строка в `pages`. Значок рисуем линией: SVG 24×24, `stroke="currentColor"`, толщина 1.7, без заливки. Эмодзи вместо значков не ставим.
5. **После правки — проверка глазами.** Открыть страницу, пройти меню, свернуть панель, переключить тему, сузить окно до телефона.
