# 04 — обновить среду

Для тех, кто разворачивал среду раньше. Твоё не трогаем: агент только добавляет бренд по семи
разделам и портал.

```
Обнови мою среду до новой версии https://github.com/SharTwoOne/modular_life_os_sreda.

1. Моя среда лежит в папке: [путь, например ~/anna-os]. Ничего в ней не удаляй и не переписывай, только добавляй.
2. Склонируй свежий репозиторий во временную папку, прочитай README и скилл modular-life-os-sreda. Коротко скажи мне, что нового.
3. Если у меня уже есть brand/ — разложи то, что там есть, на семь разделов нового шаблона: цвета, полотна, типографика, холст и формы, компоненты, образцы, можно и нельзя. Чего не хватает — спроси. Если brand/ нет — пройди вторую часть: дизайн-систему.
4. Пройди третью часть: портал с вкладками «Обо мне» и «Бренд».
5. Прогони architecture.py и check.py, покажи результат.
```

Старая страница `brand/style-reference.html`, если она у тебя есть, остаётся на месте. Портал её заменяет.
