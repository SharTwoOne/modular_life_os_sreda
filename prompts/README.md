# Промпты

Копируешь промпт целиком в Claude Code и отправляешь. Дальше агент ведёт сам и задаёт вопросы.

| Промпт | Когда |
|---|---|
| [00 — всё сразу](00-all-parts.md) | Первый раз: распаковка, дизайн-система и портал за один заход |
| [01 — распаковка](01-unpack.md) | Только первая часть: собрать среду о себе |
| [02 — дизайн-система](02-design-system.md) | Среда уже есть, собираем бренд-систему |
| [03 — портал](03-portal.md) | Бренд-система есть, собираем портал с боковым меню |
| [04 — обновить среду](04-update.md) | Ставил среду раньше (первый поток лаборатории) и хочешь бренд и портал |

**Итог первой недели:** у тебя на компьютере папка среды и портал `<Имя> OS`, в котором открываются
две вкладки: «Обо мне» и «Бренд». Бренд разложен на семь разделов: цвета, полотна, типографика,
холст и формы, компоненты, образцы, можно и нельзя.

Что нужно: Claude Code и подписка Claude от 20 $. Если будет что-то непонятно — пиши в чат лаборатории.
